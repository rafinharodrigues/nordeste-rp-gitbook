# ESTÁBULO

**Ação de Pequeno Porte**

<table><thead><tr><th width="170">Requisito</th><th>Quantidade</th></tr></thead><tbody>
<tr><td><strong>🦹 Bandidos</strong></td><td>Mínimo: 4 | Máximo: 6</td></tr>
<tr><td><strong>👮 Polícia</strong></td><td>Sempre 01 a mais que a quantidade de bandidos.</td></tr>
</tbody></table>

{% hint style="warning" %}
Apenas pistolas, no caso da Polícia usar glock e os bandidos usar Five Seven, podem ser utilizadas durante a ação.
{% endhint %}

* Não necessário agendamento de ação.

{% hint style="danger" %}
É **proibida a entrada de veículos** dentro do local do roubo.
{% endhint %}

* O uso de **helicópteros é proibido**.
* **Proibido atirar de dentro do perímetro para fora do perímetro**, e vice-versa.
* É **proibido a utilização de refém**.

{% hint style="success" %}
Permitido o uso de utilitários. (energético, kit médico, bandagem e analgésicos)
{% endhint %}

* É permitido subir em construções próximas ao local da ação.
* Polícia sempre deve rushar.

### Perímetro

> Perímetro somente na área do Estábulo

{% hint style="warning" %}
O respeito às regras garante uma experiência equilibrada e divertida para todos os jogadores. Infrações podem resultar em punições, incluindo advertências ou banimento.
{% endhint %}

* As regras podem ser alteradas futuramente sem qualquer aviso, por esse motivo leia sempre as regras antes de iniciar as ações.
