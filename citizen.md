# CITIZEN

## &#x20;Regras de Citizen / Modificações Gráficas

## 1. Permitido:

* Ajustes gráficos que não alterem a jogabilidade competitiva (ex: FPS boost, melhoria de performance, redução de sombras, configs de resolução)
* Packs visuais puramente estéticos (skins, interface/HUD, cores, iluminação)

## 2. Proibido:

* Qualquer modificação que dê vantagem em PvP, incluindo:
  * Remoção ou transparência de:
    * Água
    * Vegetação (mato, árvores, arbustos)
    * Vidros, muros ou estruturas
  * Redução extrema de partículas (fumaça, explosões) para visão limpa
  * Modificação de LOD/draw distance para enxergar players além do padrão
  * Qualquer tipo de highlight em players/inimigos

## 3. Outras vantagens competitivas proibidas:

* Filtros que aumentem visibilidade de players (reshade abusivo)
* Packs que removam recoil visual ou efeitos de arma
* Sons modificados para localizar players com mais precisão que o padrão
* Alterações que deixem o mapa “limpo” de obstáculos visuais

## 4. ScreenShare (SS):

* O player deve apresentar todos os arquivos/modificações quando solicitado
* Recusa ou ocultação = punição direta
* Uso de arquivos não autorizados = considerado vantagem indevida

## 5. Penalidades:

* Uso de vantagem leve: advertência + remoção obrigatória
* Reincidência: banimento temporário
* Vantagem clara/intencional: banimento permanente
